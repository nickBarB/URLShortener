# URLShortener

Консольное приложение на Java 21 для сокращения ссылок. Поддерживает вход по UUID,
лимиты переходов, срок действия ссылок и уведомления. Данные хранятся в одном JSON-файле.
Короткие адреса используются внутри приложения; HTTP-сервер не предусмотрен.

## Запуск

Требуется JDK 21 или новее. Maven и зависимости загружаются через Maven Wrapper.
Сборка и запуск выполняются из корня проекта:

```bash
./mvnw clean verify
java -jar target/URLShortener-1.0.jar
```

В Windows команда сборки — `mvnw.cmd clean verify`.

## Команды

Первый `create` предлагает создать пользователя или войти по существующему UUID.
UUID используется для повторного входа; восстановление потерянного идентификатора не предусмотрено.

Пример сеанса:

```text
> create https://example.com/page 5
> 1
> list
> whoami
> exit
```

Ответ `1` создаёт пользователя. Для следующего сеанса используется `login <uuid>`
с идентификатором из вывода программы.

| Команда | Назначение |
|---|---|
| `create <url> [лимит]` | Создание ссылки |
| `login <uuid>` / `logout` | Вход / завершение сессии |
| `whoami` | Текущий UUID |
| `list` | Ссылки текущего пользователя |
| `open <код или ссылка>` | Открытие исходного URL |
| `edit-limit <код> <лимит>` | Изменение лимита |
| `delete <код>` | Удаление ссылки |
| `notifications` | Чтение уведомлений |
| `help` / `exit` | Справка / выход |

Редактирование и удаление доступны владельцу. Переходы блокируются по истечении срока
или при исчерпании лимита. Просроченные ссылки удаляются фоновой задачей.
TTL задаётся конфигурацией; у существующей ссылки редактируется только лимит.
Переход засчитывается при выдаче URL, даже если браузер недоступен.
Уведомления выводятся при входе и после команд.

## Настройки и данные

Конфигурация: [config/app.properties](config/app.properties). Изменения применяются после перезапуска.
По умолчанию срок действия — 24 часа, лимит — 1000 переходов, интервал очистки — 1 минута.

- `data/shortener.json` — пользователи, ссылки и уведомления; создаётся при первом сохранении.
- `logs/` — технические журналы.

Пути отсчитываются от рабочего каталога. Для резервного копирования достаточно скопировать
JSON-файл после остановки приложения.

## Тестирование

Unit- и интеграционные тесты проверяют валидацию, права владельца, лимиты, TTL,
уведомления, сохранение данных, конкурентный доступ и откат при ошибках записи.

```bash
./mvnw test
./mvnw verify
```

`verify` выполняет сборку, тесты и проверку форматирования Spotless.
Исправление форматирования:

```bash
./mvnw spotless:apply
```
